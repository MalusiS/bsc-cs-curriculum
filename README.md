## Rules of engagement

1. Never consume without producing (30 min output per hour of lecture).
2. Commit at least once per study day — conventional commits (`feat(cs50): week1 mario pyramid`).
3. Build in public; document failures.
4. 3-2-1 backups: local + GitHub + external SSD; 2 media types; 1 off-site. Push daily, back up Obsidian weekly.

## Self-grading rubric (4.0 scale, credit-weighted)

| Grade | Points | Exam score |
|---|---|---|
| A | 4.0 | ≥ 90% |
| B | 3.0 | 80–89% |
| C | 2.0 | 70–79% |
| D | 1.0 | 60–69% |
| F | 0.0 | < 60% |

`GPA = Σ(grade points × credits) / Σ(credits)`

Course grade weighting: coursework 30% · midterm 30% · final 40%.
